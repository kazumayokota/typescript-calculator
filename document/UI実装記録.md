# UI実装記録

## 1. 実施範囲

実装手順書の「フェーズ3：React画面の実装」を実施した。フェーズ3完了時点では計算処理を含めず、その後のフェーズ4・5で共通処理と状態管理を接続した。現在の画面は実際に計算できる。

## 2. 実装したコンポーネント

| コンポーネント | 責務 |
| --- | --- |
| `Calculator` | 計算表示とキーパッドの構成 |
| `CalculatorDisplay` | 計算1・計算2の2段表示 |
| `CalculatorKeypad` | 設計書どおりのキー配置 |
| `CalculatorButton` | 共通button要素と視覚種別 |

## 3. 画面配置

```text
┌─────────────────────────────┐
│ 計算1：12345 +              │
│ 計算2：6789                 │
├─────────────────────────────┤
│  7   8   9 │ C   CE         │
│  4   5   6 │ +   -          │
│  1   2   3 │ ×   =          │
│      0   . │ ÷   =          │
└─────────────────────────────┘
```

- `=`は2行分の縦長ボタンとした。
- `0`は最下段中央、小数点はその右とした。
- 数字、演算子、クリア、イコールを色で区別した。
- 画面幅に応じて縮小できるレイアウトとした。
- 長い表示値は表示領域内で横スクロールできる。

## 4. アクセシビリティ

- 操作要素はすべてネイティブ`button`とした。
- 各ボタンに日本語のアクセシブル名を設定した。
- 計算1、計算2を個別に識別できるようにした。
- 計算2へ`aria-live="polite"`を設定した。
- キーボードフォーカスを黄色のアウトラインで表示する。
- Tab、Enter、Spaceはネイティブbuttonの標準動作を利用する。

## 5. UIプレビュー

初期状態は詳細設計書どおり計算1・計算2とも空表示である。ボタン操作はreducerへ接続済みであり、数字入力、四則演算、`C`、`CE`、`=`が動作する。
