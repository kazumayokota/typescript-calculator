## 4. 再現性に関する設定

- `package.json`の直接依存は完全なバージョンで指定する。
- `package-lock.json`を使用する。
- `.npmrc`の`save-exact=true`により、今後追加する直接依存も完全なバージョンで保存する。
- `.npmrc`の`engine-strict=true`により、Node.js要件外の環境ではインストールを失敗させる。
- CIや別端末では`npm install`ではなく`npm ci`を使用する。
- TypeScriptは`strict`、`noImplicitAny`、`noImplicitReturns`、`noUncheckedIndexedAccess`、`exactOptionalPropertyTypes`を明示的に有効にする。

初期`package-lock.json`のSHA-256：

```text
0ED2200AFAD2072BD78D302BC3C051C91E451606EF6DC21892E20ECF85EFDF51
```

依存関係を正規の手順で更新した場合、このハッシュは変わる。更新時には採用理由、変更バージョン、検証結果を本書へ追記する。

## 5. この端末での利用方法

既存のシステムPATHには旧Node.jsが残っているため、作業開始時にプロジェクト用Node.jsを現在のPowerShellセッションへ読み込む。

```powershell
Set-Location D:\Study_folder\JavaScript\React\Calc_app
. .\scripts\Use-ProjectNode.ps1
```

次の出力を確認する。

```text
Using Node.js v24.21.0
Using npm 11.19.0
```

その後、アプリケーションディレクトリで操作する。

```powershell
Set-Location .\app
npm ci
npm run dev
```

別端末ではNode.js 24.21.0を通常の方法で導入してよい。`.nvmrc`または`.node-version`を認識するバージョン管理ツールも利用できる。
